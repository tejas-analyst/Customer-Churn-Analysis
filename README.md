# Customer-Churn-Analysis
Customer Churn Prediction using Ensemble Learning techniques with model deployment on Streamlit Cloud.
The model performs well in predicting non-churn customers and achieves strong recall for churn prediction.

Important Findings:
Customers with high age and high balance show higher churn probability
Inactive members are more likely to churn
Geography also impacts churn behavior
Although the model accuracy is good, accuracy alone is not sufficient because the dataset is imbalanced. Precision and recall provide better evaluation of churn prediction performance.
